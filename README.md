# 🍷 Red Nights – Restaurant Website

A visually engaging and responsive restaurant website built with HTML and CSS.  
This project showcases a fictional fine dining restaurant called **Red Nights**, offering users an immersive, elegant browsing experience.

---

## 🔥 Features

- ✅ Clean and responsive layout
- ✅ Hero section with call to action
- ✅ Gallery of featured dishes
- ✅ About us section
- ✅ Customer feedback/testimonials
- ✅ Contact section with information and message form

---

## 💻 Technologies Used

- **HTML5**
- **CSS3**
- **Google Fonts** (`Inter`)
